# Runway Room

A cash runway and scenario planner for early-stage founders.

**Status:** In development. Nothing is live yet.

## What it will do
- Turn a transactions CSV into monthly burn and runway
- Say whether the company is default alive or default dead
- Test the effect of a new hire, revenue growth or a fundraise
- Answer reverse questions: how much to raise, and when a hire is affordable
- Draft an investor update from the numbers

## Planned stack
Next.js, TypeScript, Tailwind CSS, Recharts. No database: data stays in the browser.
